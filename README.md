# Event Booking System — Java & JavaFX

A full-stack desktop application built in Java with JavaFX for managing event bookings, developed as a Software Design & Analysis semester project.

## Features
- Role-based dashboards for Admin, Customer, and Venue Owner
- Venue search, booking requests, and payment records
- User authentication with forgot/reset password flow
- Revenue reports and system overview for Admin
- MySQL database integration

## Architecture
- **MVC Pattern** — Controllers, Models, Services, DAOs separated cleanly
- **JavaFX + FXML** — UI designed with scene builder
- **MySQL** — Full database connectivity via JDBC
